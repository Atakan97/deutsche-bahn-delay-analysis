# =============================================================================
# requirements.txt — Slim dependency list for the prediction API container.
#
# This is intentionally separate from the project-wide requirements-dev.txt.
# The API only needs libraries to:
#   1. Serve HTTP requests (fastapi, uvicorn)
#   2. Deserialise the model artifact (joblib, scikit-learn, xgboost)
#   3. Construct feature vectors (numpy, pandas)
#
# Libraries NOT needed in the API container:
#   - httpx, pydantic (pipeline only — API uses FastAPI's built-in Pydantic)
#   - psycopg2-binary (database access — API is stateless)
#   - prefect (orchestration — runs in GitHub Actions, not the API)
#   - mlflow, shap, matplotlib (training/analysis only)
#   - dbt-core, dbt-postgres (transformation only)
#   - pytest, ruff (development only)
# =============================================================================
